# Homa Ghost Marzban Reseller Panel

پنل فارسی و ریسپانسیو نمایندگی مرزبان برای نصب روی cPanel، ساخته‌شده با Laravel 12 و MySQL.

## نسخه فعلی

`v0.2.0` — نصب‌کننده فارسی cPanel

## امکانات نسخه 0.2.0

- داشبورد جداگانه مدیر و نماینده؛
- کیف پول ریالی با دفترکل دوبل و تراکنش‌های Idempotent؛
- ثبت درخواست شارژ با کد رهگیری یا رسید خصوصی؛
- تأیید و رد شارژ توسط مدیر؛
- اتصال رمزگذاری‌شده به Marzban API؛
- تعریف پلن براساس حجم، زمان، قیمت، Proxy و Inbound؛
- ساخت اکانت و تمدید همراه ریست مصرف؛
- تطبیق عملیات نامشخص و جلوگیری از کسر یا برگشت دوباره؛
- پوسته روشن و تاریک بدون وابستگی به CDN؛
- نصب‌کننده تعاملی و تمام‌فارسی cPanel با بررسی خودکار پیش‌نیازها و دیتابیس.

## نصب

راهنمای کامل فارسی در [README-fa.md](README-fa.md) قرار دارد.

```bash
bash cpanel-install.sh
```

نصب‌کننده اطلاعات دامنه، دیتابیس، مدیر و کارت بانکی را مرحله‌به‌مرحله دریافت می‌کند و `.env` را خودکار می‌سازد. پیش از اجرا فقط Document Root زیردامنه را روی پوشه `public` پروژه قرار دهید.
