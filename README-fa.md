# پنل نمایندگی مرزبان هما گوست — نسخه 0.3.0

این نسخه برای نصب روی cPanel ساخته شده و فقط دامنه فعلی پروژه را پوشش می‌دهد:

- ورود جداگانه مدیر و نماینده؛
- تعریف نماینده و پیشوند یکتای نام کاربری؛
- اتصال رمزگذاری‌شده به API مرزبان؛
- تعریف پلن با حجم، مدت، قیمت، Proxy و Inbound؛
- کیف پول ریالی با دفترکل دوبل، سندهای متوازن و تاریخچه تغییرناپذیر؛
- ثبت درخواست شارژ با کد رهگیری یا تصویر رسید خصوصی؛
- تأیید یا رد درخواست توسط مدیر؛
- ساخت اکانت جدید و تمدید/ریست مصرف از کیف پول؛
- جلوگیری از کسر تکراری با کلید یکتا و برگشت خودکار مبلغ در شکست قطعی؛
- نگهداری عملیات با نتیجه نامشخص برای تطبیق، بدون برگشت کورکورانه پول؛
- صفحه مدیریت عملیات مرزبان و تطبیق دستی/زمان‌بندی‌شده؛
- رابط فارسی، ریسپانسیو و پوسته روشن/تاریک بدون CDN.

## پیش‌نیازها

- PHP 8.2 تا 8.5؛
- MySQL 8 یا MariaDB 10.6 به بالا؛
- Composer 2؛
- افزونه‌های PHP: `bcmath`, `ctype`, `curl`, `fileinfo`, `json`, `mbstring`, `openssl`, `pdo_mysql`, `tokenizer`, `xml`؛
- یک دامنه یا زیردامنه دارای SSL؛
- دسترسی HTTPS هاست cPanel به آدرس پنل مرزبان.

این پروژه روی Laravel 12 تنظیم شده است تا با PHP 8.2 هاست‌های اشتراکی سازگار بماند.

## نصب روی cPanel

1. در cPanel یک دامنه یا زیردامنه دارای SSL بسازید.
2. در MySQL Database Wizard یک دیتابیس و کاربر بسازید، کاربر را به دیتابیس متصل کنید و `ALL PRIVILEGES` بدهید.
3. فقط فایل ZIP نسخه را از بخش GitHub Releases دانلود کنید؛ بسته Source Code برای نصب مناسب نیست.
4. ZIP را در پوشه ریشه دامنه، مانند `public_html`، آپلود و Extract کنید. فایل‌های Release مستقیماً در همان مسیر باز می‌شوند و پوشه اضافه نمی‌سازند.
5. مطمئن شوید فایل `install.php` مستقیماً در ریشه دامنه قرار گرفته است.
6. دامنه را در مرورگر باز کنید. نصب‌کننده فارسی به‌صورت خودکار نمایش داده می‌شود.
7. اطلاعات دیتابیس، مدیر و کارت بانکی را وارد و «شروع نصب» را بزنید. نصب‌کننده اتصال MySQL را آزمایش و همه تنظیمات را خودکار ایجاد می‌کند.
8. پس از پیام موفقیت وارد پنل شوید؛ ابتدا «اتصال مرزبان»، سپس «پلن‌ها» و در پایان «نمایندگان» را بسازید.
9. برای نصب نیازی به Terminal، SSH یا Composer ندارید.

برای تطبیق خودکار عملیات نامشخص می‌توانید بعداً از بخش Cron Jobs خود cPanel، بدون بازکردن Terminal، این فرمان را هر دقیقه ثبت کنید:

   ```cron
   * * * * * cd /home/USER/public_html && php artisan schedule:run >/dev/null 2>&1
   ```

## تنظیم اتصال مرزبان

- Base URL باید HTTPS و بدون `/dashboard` یا مسیر اضافه باشد؛ نمونه: `https://panel.example.com:8443`.
- از حساب مدیر محدودشده در مرزبان استفاده کنید، نه رمز اصلی سرور.
- بررسی SSL را فقط وقتی خاموش کنید که گواهی داخلی دارید و ریسک آن را پذیرفته‌اید.
- پس از ذخیره، حتماً دکمه «تست اتصال» را بزنید.
- در هر پلن، نام تگ‌های Inbound باید دقیقاً با مرزبان یکی باشد. نمونه:

  ```json
  {"vless": {}}
  ```

  ```json
  {"vless": ["VLESS_INBOUND_TAG"]}
  ```

## رفتار تمدید

تمدید از آخرین زمان انقضا (اگر هنوز آینده باشد) یا از زمان فعلی محاسبه می‌شود. حجم پلن جدید اعمال و مصرف ریست می‌شود. اگر اعمال حجم/زمان موفق شود ولی ریست مصرف بعد از دو تلاش پاسخ ندهد، عملیات با وضعیت «نیازمند بررسی» نگه داشته می‌شود و پول خودکار برنمی‌گردد تا تمدید رایگان ایجاد نشود.

## امنیت و نگهداری

- `.env`، `storage` و کل ریشه پروژه نباید از وب قابل دسترسی باشند؛ فقط پوشه `public` باید Document Root باشد.
- رسیدها در فضای خصوصی ذخیره و فقط از مسیر احراز هویت مدیر دانلود می‌شوند.
- رمز پنل مرزبان با کلید برنامه رمزگذاری می‌شود. از `APP_KEY` نسخه پشتیبان امن بگیرید؛ بدون آن رمزها قابل بازیابی نیستند.
- برای تغییر سابقه کیف پول، رکورد قبلی را ویرایش نکنید؛ تراکنش اصلاحی ثبت کنید.
- برای کنترل توازن و بازسازی کش موجودی از دفترکل، ابتدا `php artisan homa:reconcile-wallets` و فقط پس از بررسی گزارش، در صورت نیاز `php artisan homa:reconcile-wallets --fix` را اجرا کنید.
- `APP_DEBUG=false` و `SESSION_SECURE_COOKIE=true` را در محیط واقعی حفظ کنید.
- از دیتابیس و فایل `.env` روزانه بکاپ رمزگذاری‌شده بگیرید.

## اجرای تست‌ها در محیط توسعه

```bash
composer install
php artisan test
```

روش قدیمی `bash cpanel-install.sh` همچنان برای مدیران سرور در بسته باقی مانده، اما برای نصب عادی cPanel لازم نیست.
